## ⏱️ Complexity Analysis

Understanding complexity is an important part of DSA.

### Common Time Complexities

```text
O(1)        → Constant
O(log n)    → Logarithmic
O(n)        → Linear
O(n log n)  → Linearithmic
O(n²)       → Quadratic
O(2ⁿ)       → Exponential
O(n!)       → Factorial
```

### Goal

> Write solutions that are **correct, efficient, scalable and optimized**.
